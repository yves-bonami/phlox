# Phlox

Phlox is a Rust-based, extensible integration engine for building flows between protocols and systems. It is not a one-to-one Node-RED clone.

## Architecture documents

- [Design](docs/design.md) — consolidated technical architecture.
- [Accepted decisions](docs/decisions.md) — 80 decisions from the design discussion; canonical where documents conflict.
- [MVP plan](docs/mvp.md) — staged implementation and acceptance criteria.

**Status:** Design phase. No runtime or plugins implemented in this repository yet.
